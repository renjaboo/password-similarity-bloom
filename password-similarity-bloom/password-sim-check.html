Password twin check

Some passwords are just a known weak password in a new outfit. This tool turns each password into a Bloom-filter fingerprint and measures how closely it matches a list of 204 leaked passwords. Everything runs in your browser; nothing you type is sent anywhere.

Bi-grams

Your password is padded with spaces and cut into overlapping pairs. Each pair sets 20 bits.

How it works
  1. Pad the password with a space on each side and split it into two-character pieces (bi-grams).
  2. Hash each bi-gram with SHA-256 (f) and MD5 (g). The bits at (f + i·g) mod 1000, for i = 0 to 19, are switched on.
  3. Combine the bi-gram filters with a bitwise OR to get the password’s fingerprint.
  4. Compare fingerprints with Jaccard, Dice and Cosine similarity. A best Dice score of 0.70 or more means rejected.

Similarity is not strength: a password can be unlike every entry here and still be easy to guess. The original command-line tool accepts 8 to 10 characters; this page accepts any length up to 32.
